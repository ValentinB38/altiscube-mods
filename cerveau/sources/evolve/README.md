# Source : formation Evolve (à venir)

Formation achetée par Valentin, présentée comme l'une des meilleures pour l'e-commerce aux US. Les vidéos arriveront par Google Drive.

## Méthode
- Un fichier de résumé par module (`module-01-....md`), avec les règles concrètes, les chiffres et les exemples.
- Les règles nouvelles ou différentes vont dans `playbook/`, avec le renvoi « EV module X ».
- Quand Evolve contredit Adam Citron ou nos chiffres, on garde les deux versions dans le playbook et on note le désaccord.
- **Jamais de copie des vidéos, des slides ou des documents de la formation** : ce contenu est payant. Uniquement des résumés et des règles reformulées.
- **À stocker dans un dépôt privé, pas ici** : altiscube-mods est public. Quand la formation arrivera, il faudra créer un dépôt privé (par exemple `unlined-cerveau`) dédié à ces résumés.
